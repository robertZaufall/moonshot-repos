# Moonshot AI Repository Atlas

Static, searchable atlas of active [moonshotai](https://github.com/moonshotai) repositories.

[Visit the atlas](https://glaubi.net/moonshot/) · [Maintenance guide](AGENTS.md)

Python 3.10+ and GitHub CLI authentication (or GITHUB_TOKEN) are required to refresh: `python3 update_stats.py`. Eligibility: more than 200 stars, non-fork, non-archived, pushed in the previous three calendar months. Generated HTML and stats_history.json are committed. GitHub Actions refreshes daily and deploys GitHub Pages.
